# 契約30: R33 — 全候補の撮影敵対レビュー・干渉修正・小物増強・難化ジッター

## ユーザー要望（2026-08-12）
1. ラダーシェルフ棚段で人形が上の棚板に干渉 → もう少し小さく
2. **全候補ポイントを複数画角で撮影し、干渉が起きていないか敵対レビュー**
3. 1Pの後ろの低い棚（TV台）にもっと小物を
4. もっと難しく

## 実装
- **撮影パイプライン**（再利用可能）:
  1. `scene.ts` の `__spotShot(i, ang)` プローブ: 候補地 i にテスト個体を強制配置（本番と同じ
     placeCloneAt=接地スナップ込み）→ カメラを正面/±50°に配置 → **同期 renderer.render →
     toDataURL**（preserveDrawingBuffer 不要の同一タスク capture）
  2. scratchpad の shot-server.mjs（127.0.0.1:9977）がページからの POST を jpg 保存
  3. make-sheets.mjs（sharp）でラベル付きコンタクトシート合成（16セル/枚）
  4. scout-opus ×2 並列で画像敵対レビュー（CLIP/FLOAT/BURIED/EASY）
- **干渉修正**: 棚の中系スポット（本棚8+ラダー4）を s0.4→0.32（ユーザー承認の最小例外。
  テストの下限アサートも 0.3 へ）
- **小物増強**: TV台に本の山/キャンドル/花瓶、レコードコンソールに写真立て、サイドボードに
  ミニ多肉を追加（計17プロップ・snapCap 吸着）
- **難化ジッター**: placeHiddenPlush でシード派生（core.nextRng）の 向き±30°・スケール0.8〜1.0 を
  各個体に適用。決定的＝全クライアント同一で同期安全

## 検証
- レビュー指摘の全適用後に再撮影 or 該当スポットのみ __spotShot で個別確認
- typecheck / テスト / secret-scan green → デプロイ
