# 契約23: ユーザーのぬいぐるみ2体を部屋に配置

委譲先: implementer-opus / ダイヤル: ゴール委譲

## 目的
- 要求: ユーザー所有の実在のぬいぐるみ2体（写真提供済み — 下記に詳述）を、ゲームの部屋にプロシージャル3Dモデルとして配置する。大きさは実物23cm相当
- ゴール: ユーザーが自分の大切なぬいぐるみを部屋の中に見つけて嬉しくなる、質の良い置物
- 成功条件: 合格基準の全コマンド exit 0 + 配置・見た目の確認報告（status行必須）

## ぬいぐるみの特徴（写真からの詳細記述 — エージェントは画像を見られないため忠実に読むこと）

### 1体目: ダルメシアンの子犬のぬいぐるみ
- 白いパイル地（ぬいぐるみらしい柔らかい質感）に**黒の不規則なまだら斑点**（大小さまざま・顔にも数個）
- **大きく垂れた黒い耳**（頭頂から左右へ、顔の横に沿ってだらんと垂れる。片耳が少し立ち気味でも可愛い）
- 黒く丸い大きな鼻（マズルの先）・茶色の丸いボタン目・マズルは白
- 服: **デニムのオーバーオール**（濃紺・胸当てと肩紐・膝に軽い破れ表現があるとなお忠実）+ 白い襟/シャツ
- 座り姿勢（お尻をつけ、短い脚を前に投げ出す）

### 2体目: 青いパンダのぬいぐるみ
- 白いボディに、**耳・目のまわりのパッチ・腕/脚の先が鮮やかな青**（パンダの黒配置がそのまま青になったデザイン）
- 茶色の丸い鼻・黒い丸目（青いパッチの中央）・**にっこりした小さな口**（縫い目風の曲線）
- 服: **白いワンピース**（柔らかい生地感・襟つき。小さな模様が散っていると忠実）
- 座り姿勢

### 配置
- **2体はソファ（または適切な家具）の上に寄り添って並んで座る**（ベンチの写真の構図: パンダが左・ダルメシアンが右、肩が触れ合う距離）
- サイズ: 実物23cm相当（ゲーム内スケールではトランプカード(約9cm)の2.5倍程度の座高を目安に、部屋との対比で自然に見えるサイズを選ぶ）
- 卓上のゲームプレイの視界を妨げない位置。ただしタイトルのシネマカメラのカットで時折映り込むと嬉しい（映えるカットがあれば調整可）

## 実装の質
- プロシージャルのみ（球・カプセル・ラス地表現はマテリアルのroughness/ノイズテクスチャで）。斑点はCanvasテクスチャで
- ぬいぐるみらしい「ふっくら感」（頭が大きめのデフォルメ・丸い手足）
- 静的オブジェクトなので既存の統合バッファ（MERGE_FURNITURE）に載せるか単独メッシュ数個で（描画コール増は最小限に・報告）
- 影・ライティングと調和（既存の部屋の光で自然に見えること）
