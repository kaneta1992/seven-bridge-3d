# 契約36: R39 — 親番ルール変更（一番負けている人が親）

## ユーザー指定（2026-08-12）
「次のラウンドの親番を一番負けている人に」

## ルール（docs/requirements.md §2.6 更新済み）
- 初回: ルーム順先頭（従来どおり）
- 2ラウンド目以降: **その時点で累計失点が最大のプレイヤーが親**（旧: 前ラウンド勝者・流局は継続）
- 同点最下位が複数: 直前の親が同点内なら親継続、いなければ席順で最初の同点者
  （決定的＝ホスト権威・リプレイ・全クライアントで同一結果）
- 最初のツモは親の左隣から（従来どおり）

## 実装
- `src/core/engine.ts` startRound: computeTotals で累計を取り max→タイブレーク。lastWinner は
  親決定に使わなくなった（勝者表示・スコア用途は従来どおり残る）
- テスト: 旧ルールの2件を新ルール2件（最大失点者が親 / 同点タイブレーク2態）へ置換
