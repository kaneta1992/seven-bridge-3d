# 契約27: R29 — 部屋の高密度化（かくれんぼ難度アップ）

## 目的
「まだ部屋がスカスカでかくれんぼが簡単。もっと高密度に、床・壁・天井の情報量も増やして
見つけにくくしたい」（2026-08-12 ユーザー要望）。

## 3本柱
1. **Meshy家具 第2弾 14種**（+15配置）: fireplace（-z壁・窓の左）/ loveseat（+z壁）/
   laddershelf / barcart / recordconsole / globe / coatrack / dogbed（暖炉前）/ toybox /
   cushions / mirror（立て掛け）/ chandelier（梁吊り・topY）/ hangplant×2（梁吊り）/ suitcases。
   既存と合わせ **26モデル・30配置**
2. **躯体テクスチャ化**（`src/render/roomTextures.ts`・全Canvasプロシージャル・D7遵守）:
   床=木目フローリング（千鳥張り・節・目地）/ 壁=壁紙（ストライプ+ダマスク+ノイズ）+腰壁+幅木 /
   天井=板張り / ラグ=オリエンタル紋様のテクスチャ円盤（単色円盤+2リングを置換）
3. **かくれんぼ候補地の拡充**: 新家具のAABBを hideSpots.ts の BOXES へ転記し、
   暖炉の中・マントルの上・犬用ベッド・おもちゃ箱の中・トランクの上など厳選スポットを追加

## 技術
- merge-furniture.mjs をマルチアトラス対応（16タイル/枚を超えたら自動分割。26テクスチャ→
  4096×2枚 = 家具全体で**2描画コール**）。`topY` で吊り家具（バウンディング上面基準）
- 生成は state.json 差分実行（既存12点はスキップ・追加14点のみ課金 ≈210クレジット）
