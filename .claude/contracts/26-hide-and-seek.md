# 契約26: R28 — かくれんぼ（隠れパンダ & 隠れダルメシアン）

## 目的
ソファの固定2体はそのままに、パンダとダルメシアンを**もう1体ずつ**、ラウンドごとにランダムな
場所へ出現させて見つける「おまけ要素」を追加する（2026-08-12 ユーザー要望）。

## ユーザー要件と実現方法
| 要件 | 実現 |
|---|---|
| 候補地を100か所ぐらい確保 | `src/render/hideSpots.ts` に候補103か所（厳選57+壁沿い自動生成46）。全席可視フィルタ通過73か所を採用 |
| 意味のある位置（家具の隙間・一緒に置く） | 家具ごとに設計: 座面/天板/棚上/カゴの中/鉢の脇/家具の前/壁の隙間/TVの上/ラグの縁 |
| 全プレイヤーから見える | 6席の仮想視点（半径6.5・高さ3.4）からのレイ vs 家具AABB（実測値）で遮蔽検証。1席でも隠れる候補は自動除外 |
| 全プレイヤーで配置同期 | 共有シード = ルームコード + ラウンド番号（全員が独立導出可能・**プロトコル変更なし**）。候補地は純計算＝全端末同一 → 決定的shuffle（core の mulberry32）で同一配置 |
| サイズ可変・極端に小さくしない | スポット毎スケール 0.4〜0.6（基準座高1.05に対して）。0.4未満は不使用 |
| プレイするたびランダム | ラウンド毎に置き直し（シードにラウンド番号を含む）。ソロはゲーム毎乱数ベース |

## 実装
- `hideSpots.ts`: 候補地カタログ+可視性検証（モジュールロード時・純数学・GLBロード状態に非依存＝
  同期ずれゼロ）。`__hideSpotsDebug` で保守時に遮蔽内訳を観測可能
- `scene.ts`: `setHideSeed(seed)` / `placeHiddenPlush()`。ロード済みぬいぐるみGLBを clone
  （ジオメトリ/マテリアル共有＝Meshy費用・メモリ追加なし）し、バウンディング底面を接地。
  `__hiddenProbe` で現在配置を検証可能
- `plushReaction.ts`: register に onFire コールバック追加 + unregister。隠れ個体も既存の
  「ズーム注視1.5秒」リアクション（ハート+はねる）で反応する
- 発見演出: 初回リアクション発火時に一度だけ `🐼/🐶 かくれんぼ〇〇 みつけた！` バナー + SFX（app.ts）

## 負の制約
- src/core 非改変（shuffle の import のみ）/ 通信プロトコル非改変 / Bloomレイヤ・影は不参加
- タイトルデモにはシードを注入しない（かくれんぼは対局中のみ）
