## アーキテクチャ要求（凍結事項 — 内部実装は自由）
- **ドライバ境界**: UI/3D層はゲームに直接触れず、「アクションを送る / 状態スナップショット（PlayerView相当）を受け取る」の抽象（ドライバinterface）越しに動作させる。本契約ではローカル実装（エンジン直結・ホットシート）を提供し、契約03が同一interfaceのネットワーク実装を追加できる形にする（この目的での interface 新設を許可する）
- `src/core/**` は**変更禁止**（エンジンに不足があれば blocked で報告）
- 3Dアセットは**すべてプロシージャル生成**（カード面はCanvasテクスチャ、外部URL/バイナリアセット禁止 — 要件D7）
- ホットシートモード: 手番プレイヤーの視点に切り替えて全席を1台で操作（受け渡し確認画面を挟み他家の手札を覗けないようにする配慮は不要 — デバッグ用途）。鳴きウィンドウは全席の鳴き可否を確認し、鳴けるプレイヤーがいる場合のみ選択UIを出す
- モバイル縦画面: タッチ操作・縦長ビューポートでカメラとHUDを再構成。`resize`/回転で動的追従（要件§3.2追記）
- UIテキストは日本語
