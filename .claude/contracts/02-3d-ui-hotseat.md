## 改善ラウンド3: 3D配置と手札UXの刷新（2026-08-09 追記 — この追記が既存記述に優先する）
ユーザーが実プレイのスクリーンショット付きで報告した6点。すべて必須:

2. **山札と捨て札を近づける**: 現状 deckPos(0.95,_,0) と discardStart(-0.95,_,0) は遠すぎる。中央付近にコンパクトにまとめる（1の領域設計と併せて）

4. **ドラッグ中のポインタ追従**: 並び替えのドラッグ中、掴んだカードがポインタ位置に追従して動く視覚表現にする（現状は挿入位置が変わるだけで掴んだ感がない）
5. **捨てる/メルド公開もD&Dで**: 手札カードを上方（卓エリア）へドラッグ＆ドロップで捨てる。複数選択→ドラッグでメルド公開。付け札も対象メルドへのドロップで行えると理想（設計は委ねるが、既存のボタン操作も残すこと — アクセシビリティとフォールバック）

## 改善ラウンド4: 手札インタラクションの安定化と演出（2026-08-09 追記 — この追記が既存記述に優先する）
ユーザー実プレイのフィードバック。すべて必須:

1. **フォーカスのがくがく振動を解消**: 現状カード個別の pointerenter/leave でフォーカスするため、カードが浮き上がった瞬間にポインタから外れ→戻る→また浮く、の振動ループになる。**判定をカードのDOM境界に依存させない方式に変える**こと（推奨: 手札帯コンテナ上の pointermove でポインタxから最寄りカードを算出してフォーカス。カードが動いてもポインタ位置基準なので振動しない）。カードの transform に CSS transition を付けて滑らかに
2. **ドロップゾーンの明示**: ドラッグ開始した瞬間に「どこに落とすと何が起きるか」をおしゃれに分かりやすく表示する。仕様: **場（卓中央エリア）へドラッグ=メルド公開（複数選択対応）/ 捨て札ゾーンへドラッグ=捨てる** の2ゾーンを、ドラッグ開始時にオーバーレイで可視化（例: 半透明のゾーン矩形+アイコン+ラベル「メルド公開」「捨てる」、ホバー中のゾーンをハイライト）。現状の「上方ドラッグの距離で判別」は廃止し、ゾーン当たり判定に置き換える
3. **並び替えで配り直し演出が再生されるのを止める**: 並び替え確定（commitOrder→render）時に手札DOMが再構築されて入場アニメが再生される。並び替え・フォーカス・選択などUIだけの変化ではカード要素を再利用し、transform の transition だけで滑らかに移動させること（配り直しに見せない）。新配札・ツモ・捨てなど実際に手札集合が変わったときだけ入退場演出を出す
4. **ツモ演出**: ツモったカードが一瞬で手札に入って どれか分からない。演出を入れる: 山札位置（または画面中央）にカードが大きめに表示され（~0.6秒程度）、その後扇形の挿入位置へスライドして収まる。さらに数秒間ハイライト（光る枠等）で「今引いた1枚」を識別可能に。テンポを損なわない範囲で（連打スキップ可なら尚良し）
5. **付け札もD&Dで**: 手札カードを **2DのメルドUI（.meld チップ）へも、3D卓上のメルド表示へも** ドロップで付け札できるようにする。3D側はドラッグ中に canvas 上へポインタが来たらレイキャスト等でメルドを特定（実装方式は委ねる。3Dメルドへのホバー時はそのメルドの2Dチップ側もハイライトすると分かりやすい）。ドロップ先が付け札不能ならエンジン拒否をトーストで表示（現状踏襲）
