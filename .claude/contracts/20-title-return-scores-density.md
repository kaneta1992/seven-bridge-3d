## 実装項目（4点・すべて必須）

1. **タイトル画面へ戻る機能**: 対局中いつでもタイトルへ戻れる導線（永続コントロール群にアイコン等）。誤タップ防止に軽い確認（「タイトルに戻りますか？」— 通信対戦では退室になる旨も表示）。既存の teardown 経路（リザルトの「もう一度」相当）を再利用し、リスナー/タイマー/チャネルのリーク無し。R20の画面トランジション適用
2. **デモプレイの手札を全員表向きに**: タイトル背景のデモ対局では全席の手札を**実際の絵柄で表向き表示**（現在は裏向き浮遊手札）。デモ専用の表示モードとして実装（通常対局の視界フィルタ/秘匿には一切影響させない — 判定入力の視界公正はボット側で維持済みなので、表示層だけの全公開）。カメラカットで手札が映えると良い
3. **スコアの常時表示**: スコア票を開かずとも現在の累計失点が見えるように。①自分: ヘッダ（topbar）に現在累計を表示 ②他家: 席のネームプレートに累計を併記（デザインはタイトルのデザイン言語と調和させる — 「名前 ・ 12pt」等。おしゃれな代替案があれば委ねる）。ラウンド中のリアルタイム失点ではなく確定済み累計（scores合計）でよい。値の変化時にさりげない更新演出があると良い
4. **背景の物量大幅増 + 静的1メッシュ統合**: 家具・調度品をさらに増やして高密度に（本・食器・クッション・照明器具・壁装飾・小物類など「生活感のある密度」）。**静的な背景ジオメトリは初期化時に事前統合し、描画コールを最小化**（three の BufferGeometryUtils.mergeGeometries 等でマテリアル毎に1メッシュへ。頂点カラー活用でマテリアル数自体も圧縮してよい）。動くもの（ランプの光・時計の針を動かすなら等）だけ別メッシュ。**統合前後の描画コール数とFPSを計測報告**
